## Default Permission

Pick Files app folders, reopen them from bookmarks, and locate the Documents directory.

#### This default permission set includes the following:

- `allow-pick-folder`
- `allow-open-folder`
- `allow-close-folder`
- `allow-forget-folder`
- `allow-documents-path`
