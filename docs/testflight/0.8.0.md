Agent panel: agent picker with icons, notifications that open the agent, a Live Activity, dictation, and @ mentions for symbols

1. Connect to a runtime from npm (oxbit 0.8.0) and trust the workspace. If Agent ACP is off, turn it on in Extensions. Check that Agent appears in the bottom bar.

2. Tap Agent. Check that the picker lists Codex, Claude Agent, Gemini CLI, GitHub Copilot, Cursor and Amp, each with its own icon, and that More agents opens the ACP Registry with icons.

3. Pick an agent, type a task, and tap Send without connecting first. Check that the agent starts and answers.

4. Type @ and part of a file name. Check that matching files appear and that choosing one adds an attachment. Open a source file, then type @ and the first letters of a function in it. Check that the function appears and attaches its lines.

5. Tap Dictate, allow the microphone and speech recognition, and say a sentence. Check that the text appears in the composer.

6. In More agent actions, tap Enable notifications and allow them. Send a long task and switch to another app. Check that a notification arrives when the turn ends or the agent asks for input, and that tapping it opens Oxbit on the Agent panel.

7. Repeat step 6, but after the notification arrives, swipe Oxbit away in the app switcher, then tap the notification. Check that Oxbit opens without crashing and shows the Agent panel once the workspace reopens.

8. Start a turn, then lock the phone. Check that the Lock Screen shows a Live Activity with the agent, the task and Working. On an iPhone with the Dynamic Island, check it there too. Return to Oxbit and check that the activity changes to Finished when the turn ends.

9. Send two messages that change files, then tap Restore checkpoint on the first. Check that the files return to their state before that message.

10. While a turn runs, tap New thread and start another task. Check that the thread strip shows both threads with their status.

11. On the start screen, open an SSH server folder with a long path. Check that the start screen does not scroll sideways.

Report crashes, notifications that do not arrive or do not open the Agent panel, Live Activities that do not appear, dictation that inserts nothing, or agents that fail to start, with reproduction steps, device model, iOS version, and screenshots.
