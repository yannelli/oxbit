3. After a reply, open More agent actions and tap Fork conversation. Check that a new conversation opens with the note "Forked from", then ask about something from before the fork and check that the agent remembers it. Check that history still lists the original.

4. On a runtime workspace, type @ and check that Branch diff, commits and folders appear. Attach a commit and ask the agent about it.

5. Ask an agent to change two files. Check that Apply all, Reject all and Undo all act on every pending edit.

6. While a turn runs, queue three messages and move one up. Check that they send in the new order.

7. Tap Dictate, allow the microphone and speech recognition, and say a sentence. Check that the text appears in the composer.

8. In More agent actions, tap Enable notifications and allow them. Send a long task and switch to another app. Check that a notification arrives when the turn ends and that tapping it opens Oxbit on the Agent panel.

9. On a message with a checkpoint, tap Restore files and fork. Check that the files return to their earlier state and a new conversation opens.

10. On an SSH server with a PHP or Laravel project, open Language Servers. Check that each server shows its own name and that none stays on Starting.
