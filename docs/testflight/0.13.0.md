AI inline completions with OpenRouter, a custom API, or a local model

1. Open Settings, search for AI, and turn on AI inline completions. Set AI provider to OpenRouter. Check that AI model lists suggested models with prices and scores, and that tapping one fills in AI model.

2. Tap Set API Key… and paste an OpenRouter key. Open a code file and type a few lines. Check that gray suggestion text appears and that Tab accepts it.

3. On a Mac on the same Wi-Fi, run Ollama with OLLAMA_HOST=0.0.0.0 and pull a model, for example ollama pull qwen3.5:9b. In Settings, set AI provider to Local model and AI base URL to the Mac's address, for example http://192.168.1.20:11434. Check that the pulled model shows as installed under AI model, pick it, and check that suggestions appear while typing.

4. In Settings, type quickly into AI model and other text fields. Check that no characters disappear and typing does not lag.

5. Open a workspace with a long name, such as an SSH folder. Check that the Explorer shows the name on one line and ends it with an ellipsis.

6. Open Extensions and check that Bundle Inspector is off. In the Explorer, long-press a file, choose Copy Relative Path, and check that a Copied toast shows the path and that pasting it gives the same path.

7. Look at the Activity Bar, Explorer, and toolbar icons. Check that the new icons are sharp, line up with each other, and that the selected Activity Bar item shows its indicator.

Report missing suggestions, blurry or misaligned icons, error messages, wrong prices or scores, dropped characters, and crashes, with reproduction steps, device model, iOS version, and screenshots.
