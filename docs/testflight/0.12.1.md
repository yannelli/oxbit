Vivid themes and dialog buttons

1. Open Settings, choose Color Theme, and pick Nova (dark). Check that the accent, selected rows, and code colors change, and that text stays easy to read. Repeat for Nova (light), Lagoon (dark), Lagoon (light), Ember (dark), and Ember (light).

2. With Lagoon (dark) selected, run Toggle Light/Dark Theme from the command palette. Check that it switches to Lagoon (light), and back again.

3. Open a folder and run New File from the command palette. Check that Cancel is on the left, Save is on the right, and that typing a name and tapping Save creates the file.

Report hard-to-read text, colors that do not change, buttons in the wrong order, and crashes, with reproduction steps, device model, iOS version, and screenshots.
