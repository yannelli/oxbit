Redesigned Settings, agent sessions that survive reconnects, and editor consistency fixes

1. Open Settings. Check that the sidebar lists pages, that each row shows its title and description on the left with the control on the right, and that Reset shows only on changed rows.

2. On iPhone, open Settings. Check that a page list opens first with no settings count, that a page opens on tap, and that All settings returns to the list.

3. In Settings, search for "yaml language". Check that the YAML Language Server row and its switch appear. Turn it off and on.

4. Open Language Servers, tap Configure on a server, add a file type to File Types, and check it saves. Open Edit as JSON, change a value, apply it, and check the row updates.

5. Open the Runtime page and check that the Workspace trust and Reconnect Automatically switches look as they did in 0.6.1.

6. Swipe in from the left edge and check that the left panels open with their content. Swipe in from the right edge and check that nothing opens when no panels are on the right. If the left swipe opens nothing, run Reset Panel Layout from the command palette and swipe again.

7. Open the left panels and long-press a panel title. Check that no "Drop a panel here" strips appear.

8. Open a file, edit it without saving, and rename it in the Explorer. Check that the tab shows the new name and keeps your edits, then save and check the renamed file has them.

9. Open a file, delete it from the Explorer or from a terminal, and check that its tab stays open with its text. Save it and check that the file comes back.

10. Tap one file in the Explorer and quickly tap another. Check that the second file ends up open.

11. In Search, replace a word with text that contains $1. Check that $1 is inserted as typed.

12. Connect to a runtime and save a text file larger than 2 MB. Check that the save succeeds.

13. Connect an agent on a runtime and send it a task. Background the app during the turn, reopen it, tap Runtime sessions, then Open. Check that the turn's messages replay and that it finishes.

14. Disconnect from the runtime and connect again four times, tapping Connect on an agent each time without reopening the old one. Check that each Connect succeeds.

15. On a device that still has build 0.6.1, connect to a runtime from npm (oxbit 0.7.0). Save a file, commit, and open a terminal, then stop and start the runtime and do it again. Check that no "Operation ID expired" error appears.

Report edits lost after a rename, tabs that show the wrong file, saves that fail, settings that do not save, or agent sessions that do not reopen, with reproduction steps, device model, iOS version, and screenshots.
