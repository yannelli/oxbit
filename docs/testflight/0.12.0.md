AI editing: ghost text completions and Edit Selection with AI

1. Open a folder from Files with no runtime. Tap Agent, open Agent setup for Oxbit Agent, and save an OpenAI, Anthropic or OpenAI-compatible key, or sign in with ChatGPT.

2. Open Settings, go to the Editor page, and turn on AI inline completions in the AI section. Open a code file, type the start of a function, and pause. Check that dim suggested text appears at the cursor.

3. Tap tab on the key bar and check that the suggestion is inserted. Type until a new suggestion appears, tap esc, and check that it goes away and the file is unchanged.

4. Select a few lines, run Edit Selection with AI from the command palette, and enter an instruction such as "add comments". Check that the selection is replaced and highlighted, and that one tap of Undo on the key bar restores the original lines.

5. Turn AI inline completions off, type in a file, and check that no suggestions appear.

Report suggestions that never appear, text inserted in the wrong place, edits that need more than one Undo, error messages, and crashes, with reproduction steps, device model, iOS version, and screenshots.
