Theme Editor

1. Open Extensions, find Theme Editor, and check that it is off. Turn it on.

2. Open Settings, then Appearance, and tap New Color Theme. Check that the Theme Editor opens with a preview at the top.

3. In Colors, change editor.background, for example to #123456. Check that the preview editor changes color. Type an invalid value and check that the field is marked invalid and the preview keeps the last valid color.

4. Tap the color swatch next to a translucent color, such as list.selection.background, and pick a color. Check that the value keeps its last two alpha digits.

5. In Syntax, change the keyword foreground and check the preview code. In General, rename the theme. Tap Save and Apply and check that the whole app uses the new theme. Tap Restore Previous Theme and check that the previous theme returns.

6. Tap Add Light Variant, change a color, and save. Run Toggle Light/Dark Theme after applying and check that it switches between the two.

7. Open Manage Theme Packs and tap Edit on your pack. Check that your changes are still there after closing and reopening the app.

Report controls that do not fit on the screen, colors that do not match the preview, lost changes, and crashes, with reproduction steps, device model, iOS version, and screenshots.
