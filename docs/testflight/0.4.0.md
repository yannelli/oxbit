SSH hosts, SFTP folders, and Git over SSH

1. On the start screen, open SSH Hosts and Keys. Tap Generate Ed25519 Key, then Copy public key and add it to a server's authorized_keys. Also import an existing key with Import Key… (from Files) or Import Pasted Key, including one with a passphrase.

2. Tap Add Host…, enter the server, user name, and key, then Save Host. Connect with SSH… and check that the first connection shows the host key fingerprint. Tap Trust and Connect and check that later connections skip the prompt. Try password sign-in with Save password in the Keychain on and off.

3. Open a remote folder from On a server. Open, edit, and save files. Change a file on the server while it is open, save in Oxbit, and check that the conflict is reported and your edits are kept. Create, rename, and delete files and folders.

4. In the remote folder, use Upload Files Here… and Download to Device… from the palette or the explorer menu. Check the progress, that Cancel Transfer leaves nothing behind, and that uploading an existing name is refused.

5. Clone a repository with an ssh:// or git@host:owner/repo.git URL. Check that Choose SSH Key appears when no key is saved for that server, and Confirm Host Key on first use. Commit, push, fetch, and pull.

6. Change the server's host key (or connect to a different server at the same address) and check that Oxbit refuses to connect, shows both fingerprints, and connects again only after Forget saved host key.

Report crashes, connection or transfer failures, lost edits, or host key problems with the server OS, reproduction steps, device model, iOS version, and screenshots.
