Git, GitHub, and on-device editing

1. Clone a public HTTPS repository using "Clone Repository" on the workspace screen. Confirm it opens and can be reopened from recent workspaces after restarting Oxbit.

2. Open "GitHub and Commit Author", save your name and email, and connect a GitHub token. Test cloning a private repository and confirm your account settings persist after restarting.

3. In a test repository, edit a file, inspect the diff, stage changes, commit, and check history. Test branches, fetch, pull, and push over HTTPS.

4. Without a connected computer, open JavaScript or TypeScript files. Check autocomplete, error messages, hover information, go to definition, references, and rename. Check JSON and JSONC validation and completion.

5. Check Explorer menus, Settings, tabs, and the keyboard accessory bar. Look for clipped controls, unexpected scrolling, or content hidden by the keyboard.

6. Close and reopen a workspace. Confirm saved edits remain and Source Control and language features resume.

Report crashes, failed Git operations, missing suggestions, or layout problems with reproduction steps, device model, iOS version, and screenshots.
