Tab position and save fixes

1. Open a long code file, scroll to the middle, and tap a line to place the cursor. Switch to another tab, then back. Check that the file shows the same lines and the cursor is where you left it.

2. Repeat with three or four files open, switching between them in different orders. Check that each file returns to its own position.

3. Open a TypeScript file with a language server running, so it shows colored symbols and inline type hints. Make a change that the formatter fixes, then save. Check that the colors and hints stay on screen during the save and that only the reformatted lines change.

4. Save a file several times without changes and check that nothing on screen flickers.

Report a tab that opens at the top or at the wrong line, flicker or lost colors after a save, and crashes, with reproduction steps, device model, iOS version, and screenshots.
