AI data sharing prompt and privacy manifest

1. Open a folder on this device, set up Oxbit Agent with an API key, and send a message. Check that Oxbit first asks "Share data with <service>?" and names what it sends. Tap Allow and check that the agent answers.

2. Send another message and check that Oxbit does not ask again. Quit and reopen Oxbit, send a message, and check that it still does not ask.

3. In Settings, turn on AI inline completions with a provider you have not used yet, then type in a code file. Check that Oxbit asks once for that provider. Tap Don't Allow and check that no suggestions appear and nothing else asks while you keep typing.

4. Reopen the workspace, type again, and check that Oxbit asks again for that provider. Tap Allow and check that suggestions appear.

Report a missing or repeated prompt, a request sent after Don't Allow, and crashes, with reproduction steps, device model, iOS version, and screenshots.
