SSH reconnect and folder browsing, edge swipes, and terminal fixes

1. Open a terminal, hide the panel, show it again, and open a second terminal. Check that the shell keeps running, that no "free(): invalid next size" message appears, and that no stray % shows above the prompt.

2. Open the terminal panel. Check that the terminal tabs, the + button, and the split button share one row.

3. Swipe in from the left edge of the screen and check that the left panels open. Swipe in from the right edge and check that the right panels open.

4. Open the Runtime page. Check that each SSH server name is readable and that the folder field and the Start button sit below it.

5. Connect to an SSH server and tap Browse Folders…. Move into a folder, tap Set as Home Folder, then Use This Folder. Disconnect, connect again, and check that the folder field starts at that home folder.

6. Open a folder on an SSH server, then tap the cloud button. Check that the runtime starts in that folder rather than the last runtime you used.

7. Start a runtime on an SSH server, close the app, turn on Airplane Mode for a few seconds, turn it off, and open the app again. Check that the folder reopens, or that a notice offers Reconnect, and that Reconnect works.

8. With a runtime running on an SSH server, run Switch Folder… from the command palette and pick another folder. Check that files and terminals use the new folder.

9. Open the start screen with a recent folder. Check that the remove buttons show an X icon.

10. Open Settings and choose Source Control. Check that Git Accounts and Commit Author appears as a row with a Manage Git Accounts… button.

11. Open a .zsh file and leave an if block without fi. Check that the error is underlined, and that valid Zsh syntax such as ${(f)name} is not.

Report errors when reopening SSH folders, terminals that close on their own, swipes that open the wrong side or fire while scrolling, or folders that do not list, with reproduction steps, device model, iOS version, and screenshots.
