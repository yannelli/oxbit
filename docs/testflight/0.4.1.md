Start Oxbit on an SSH server

1. On a saved SSH host (Linux x64 or an Apple silicon Mac), tap Start Oxbit on This Server… and choose a remote folder. Check that the progress shows "Installing the remote runtime…" on the first start and "Starting the remote workspace…", then the folder opens. Start it again and check that the install step is skipped.

2. In the remote workspace, open a terminal and run a command. Run a task from Tasks, and if Agent ACP is turned on in Add-ons, start an agent conversation. Check that each runs on the server.

3. Run a task that serves a web page and open its link. Check that the page loads on the device.

4. Switch to another app for a minute, come back, and check that the workspace reconnects. Turn on Airplane Mode briefly, turn it off, and check that it reconnects or offers Reconnect.

5. Close the workspace and check on the server that the Oxbit process stopped.

6. If the server cannot reach github.com, check that the start still works (the device downloads the runtime and sends it over SSH).

Report crashes, install or start failures, disconnects that do not recover, or tasks that run on the wrong machine, with the server OS, reproduction steps, device model, iOS version, and screenshots.
