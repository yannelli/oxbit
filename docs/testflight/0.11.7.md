HTML preview JavaScript

1. In a folder on this iPhone, create an HTML file with a script, such as a button that changes a heading when tapped. Open the file and tap the eye button to open the HTML preview. Check that a bar says the page has JavaScript, with a Run JavaScript button.

2. Tap Run JavaScript. Check that the bar goes away and the script runs, for example the button changes the heading.

Report previews that stay blank, a missing Run JavaScript bar, or scripts that do not run after you tap it, with reproduction steps, device model, iOS version, and screenshots.
