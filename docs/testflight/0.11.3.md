Saving settings

1. Open Settings, pick User, and change Font Family. Check that no "Settings reload failed" or "changed on disk" message appears, then relaunch Oxbit and check that the new value is still set under User.

2. Turn on airplane mode, change Tab Size under User, turn airplane mode off, and wait for Oxbit to reconnect. Check that the change saves with no "changed on disk" message and that other User settings keep their values.

3. Change a setting, force quit Oxbit right away, and reopen it. Check that the change is still set and that no settings error appears.

Report settings that do not save, values that come back after a relaunch, and any "changed on disk" or "Settings reload failed" message, with reproduction steps, device model, iOS version, and screenshots.
