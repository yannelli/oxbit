HTML previews, Korean, and the Claude plan

1. Open an HTML file that has a script, such as a button with an onclick handler, and open its preview. Check that the preview shows a bar saying scripts can load and send network data. Tap Run JavaScript and check that the script runs. Reopen the preview and check that scripts still run until you relaunch Oxbit.

2. Open Settings, set Display Language to Korean (한국어), and check that the tab bar, Settings, Explorer and Source Control show Korean text that fits on the screen. Set it back to English.

3. In a folder on this iPhone, open the agent panel, choose Claude plan in the agent setup, and check that the button reads Runtime connection and opens the runtime connection screen. Connect a runtime workspace on a computer where Claude Code is signed in with a Claude plan, choose Claude Agent, tap Start Claude Agent, and send a prompt. Check that Claude Agent replies. On a computer where Claude Code is not signed in, check that the panel says to run `claude auth login` on that computer.

Report scripts that do not run after Run JavaScript, untranslated or cut-off Korean text, and Claude plan errors, with reproduction steps, device model, iOS version, and screenshots.
