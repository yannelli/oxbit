Mobile navigation and editing

1. Open a folder on iPhone. Use More to open Terminal, Problems, Output, or Tasks, switch panels, then use Back to editor. Check that each panel and the editor fit the screen and respond to taps.

2. Open a file, bring up the keyboard, and check the editor, file path, tabs, and actions for clipped or hidden controls. Repeat on iPad and after rotating the device.

3. Open an HTML file and its preview. Check that Preview options shows blocked resource warnings and external resource controls, and that Open source returns to the file.

4. Switch between two local folders. Confirm the new folder's files and language server status appear, then reopen the first folder and check its files and edits.

5. Open a JSONC file with comments, use Format Document, and confirm the comments remain. Check JavaScript or TypeScript completion and diagnostics after switching folders.

Report crashes, layout issues, missing previews, or language errors with reproduction steps, device model, iOS version, and screenshots.
