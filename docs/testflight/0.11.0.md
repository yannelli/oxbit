Oxbit Agent: settings commands, /context, and the Oxbit Agent CLI terminal settings panels

1. Open a folder from Files with no runtime, tap Agent, and start Oxbit Agent. Send /context and check that a grid of the context window appears with a legend for the system prompt, instructions, skills, tools and messages.

2. Connect to a computer runtime from Oxbit 0.11.0 or `@oxbit/cli` 0.11.0 and start Oxbit Agent CLI. Type / and check that config, skills, hooks, mcp, instructions, providers and context appear.

3. In that conversation send /config and check that it lists numbered settings. Send /config auto-compact off, then /config again, and check that Auto-compact shows off. Send /config auto-compact on to restore it.

4. Send /skills, /mcp and /instructions and check that each lists its items with usage lines. Send /skills disable followed by a listed skill name, type /, and check that the skill is gone from the list. Send /skills enable with the same name to restore it.

5. Open Session settings in an Oxbit Agent CLI conversation and check that Auto-compact and Compact at appear next to Model and Mode.

Report crashes, commands that do nothing or show an error, settings that do not stay changed after the next message, and agents that fail to start, with reproduction steps, device model, iOS version, and screenshots.
