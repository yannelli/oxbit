Settings header, Git accounts access, and per-file language servers

1. On the start screen, tap Git Accounts and Commit Author, Clone Repository, and Runtime Connection. Check that each dialog opens on top of the start screen and closes with Done or Cancel.

2. Open a folder and go to Changes. Tap the accounts button in the Source Control toolbar and check that Git Accounts and Commit Author opens. Open Settings with the search empty and check that the Git Accounts and Commit Author button at the top of the list opens the same dialog.

3. Open Settings on iPhone and iPad. Check that the title, Keyboard Shortcuts, search, User and Workspace, the language filter, and Modified fit without clipping. Type a search with the keyboard up and check that the matching settings stay visible above the keyboard.

4. Open a TypeScript file with an error. Tap the language server button in the top bar, turn off "Language features for this file", and check that diagnostics and completion stop for that file while another open file keeps them. Turn it back on and check that diagnostics return and your settings are unchanged.

5. In Add-ons, check that ClassicOS 98 and Agent ACP are off on a fresh install. If you already use the ClassicOS 98 theme, check that it stays applied after updating.

Report crashes, dialogs that open behind other screens, layout issues, or language server problems with reproduction steps, device model, iOS version, and screenshots.
