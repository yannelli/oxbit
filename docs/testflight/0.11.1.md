Oxbit Agent: Sign in with ChatGPT

1. Open a folder from Files with no runtime, tap Agent, open Agent setup for Oxbit Agent, and pick ChatGPT plan under API. Check that the page says Not signed in and has no API key field.

2. Tap Sign in with ChatGPT. Check that a code appears with Copy code, Open sign-in page and Cancel. Tap Copy code, then Open sign-in page, and check that Safari opens the OpenAI sign-in page.

3. Sign in with your ChatGPT account in Safari, paste the code, and approve. Return to Oxbit and check that the page says Signed in with ChatGPT within a few seconds.

4. Start Oxbit Agent and check that the model picker lists GPT models. Send a short request such as "List the files in this folder" and check that the agent answers.

5. Tap Sign out in Agent setup and check that the page says Not signed in. Tap Sign in with ChatGPT, then Cancel, and check that the code goes away.

Report sign-in errors with their text, a code that never completes after you approve it, agents that fail to start or answer, and crashes, with reproduction steps, device model, iOS version, and screenshots.
