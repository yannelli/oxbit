Stay connected in the background

1. Open Settings, then Runtime, and turn on Stay Connected in the Background.

2. Connect to a runtime on your computer, or open an SSH folder. When iOS asks for location access, allow it while using the app.

3. Open a terminal and start a long command, such as ping or a build. Switch to another app for at least two minutes. Check that the blue location indicator shows, then return to Oxbit and check that the terminal is still connected and its output continued.

4. Start an agent turn, switch to another app until the turn finishes, then return. Check that the turn finished without a reconnect.

5. Close the workspace and check that the location indicator goes away. Turn the setting off and check that switching apps no longer shows the indicator.

6. In the iOS Settings app, set Location for Oxbit to Never, then repeat step 2. Check that Oxbit shows one notice that location access is off.

Report dropped terminals or agent turns, an indicator that stays after you close the workspace, battery drain, and crashes, with reproduction steps, device model, iOS version, and screenshots.

HTML preview JavaScript

1. Open an HTML file with a script, then open its preview. Open the preview options and check that JavaScript is off and the script did not run.

2. Set JavaScript to Run for this preview. Check that the script runs and that the external resources option shows as on. Set it back to Off and check that the script stops.

Inline completions with a local model

1. In Settings, under Editor · AI, turn on AI inline completions. Set AI provider to Local model (Ollama or llama.cpp), AI base URL to the LAN address of an Ollama server, such as http://192.168.1.20:11434, and AI model to a base model, such as qwen2.5-coder:1.5b-base.

2. On a line that starts with // and a space, wait for a suggestion. Check that it does not repeat the // or start with blank lines.

3. Place the cursor above existing code and wait for a suggestion. Check that it does not repeat the lines above or below the cursor.

Report scripts that run while JavaScript is off, repeated or misplaced suggestions, and crashes, with reproduction steps, device model, iOS version, and screenshots.
