Agent panel: Auto-apply edits, generated conversation titles, Ask, Accept edits and Full auto modes for Oxbit Agent, and the Oxbit Agent CLI on computer runtimes

1. Open a folder from Files with no runtime, tap Agent, and start Oxbit Agent with a saved OpenAI, Anthropic or OpenAI-compatible key. Turn on Auto-apply edits under the composer and ask the agent to change a file. Check that the change saves without a review card, that "Auto-apply on" shows, and that Undo this edit restores the file.

2. Turn Auto-apply edits off and ask for another change. Check that a review card appears and nothing is saved until you apply it.

3. Send a first message in a new conversation and wait for the reply. Check that the header title changes from your message to a short generated title, and that history shows the same title.

4. Open Session settings and set Mode to Accept edits. Ask for a file change and check that it saves without review. Set Mode to Ask and check that changes wait for review again.

5. Connect to a computer runtime from Oxbit 0.10.1 or `@oxbit/cli` 0.10.1. Tap Agent and check that Oxbit Agent CLI leads the picker. Start it and send a task. It uses the provider and keys in ~/.oxbit/agent on that computer.

6. In an Oxbit Agent CLI conversation, type / and check that goal, loop, compact, undo, mcp and skills appear. Send /goal with a small task and check that the agent keeps working until it reports the goal complete.

Report crashes, edits that save while Auto-apply edits is off, conversations that keep your first message as the title after a reply, and agents that fail to start, with reproduction steps, device model, iOS version, and screenshots.
