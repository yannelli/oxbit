Settings and the Oxbit Agent

1. Open Settings, pick User, and change Tab Size. Relaunch Oxbit and check that the new value is still set under User and that Workspace has no Tab Size value. If Workspace sets a value, check that the User row says the Workspace value overrides it and that Remove Workspace value clears it.

2. Open a .env file, edit it, and save with Format on Save on. Check that the file saves with no "Formatter is unavailable" error and no repeating settings error.

3. Open a folder from Files with no runtime, tap Agent, and start Oxbit Agent. Open the model picker and check that the Reasoning levels match the model (none for models without reasoning).

4. Type / in the composer and check that the list includes /compact, /context, /goal, /loop, /config, /skills and /undo.

5. Ask the agent to change a file, apply the change, then send /undo. Check that the file returns to its earlier text.

6. Ask the agent to "use two subagents in parallel to create alpha.txt and beta.txt". Check that two Delegated entries appear, that each opens Subagent details, that Apply change from there writes the file and the Agents view stays open, and that the agent then answers.

7. With a conversation open, switch to other apps until iOS reloads Oxbit, or force quit and reopen it. Open Agent and check for "The app reloaded. The agent restarted and loaded this conversation." and that you can keep chatting.

Report wrong saved settings, save errors, missing commands or reasoning levels, subagents that never finish, conversations that do not come back after a reload, and crashes, with reproduction steps, device model, iOS version, and screenshots.
