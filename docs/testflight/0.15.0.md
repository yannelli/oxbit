Flat layout, Source Control and the agent composer

1. Open Settings, then Appearance. Check that Layout Style shows Flat. Change it to Classic and check that the panels show as separate cards. Change it back to Flat. Close the app, open it again, and check that the start screen uses the style you selected.

2. In Flat, tap each tab in the bottom bar: Files, Search, Changes, Agent and More. Check that the bar keeps the same tabs in the same order. Open More and check that Settings and Extensions are there.

3. Open a Git folder that has changes and tap Changes. Check that each file shows the number of added and removed lines. Check that you can tap every button easily and that nothing goes past the edge of the screen.

4. Add an AI model in Settings, then tap the sparkle button in the message field. Check that it writes a commit message. Edit the message and tap Commit. Open Commits and check the new commit.

5. Make changes to two or more files. Open the menu next to Commit and tap Commit with AI. Check that the dialog lists the proposed commits and that you can edit a message or move a file to a different commit. Tap Commit All and check the commits. Check that files you left out of the plan keep their staged state.

6. Open Agent. Check that the bottom of the message field shows the agent name and a shield button. Tap the shield and check that Auto-apply edits turns on. Tap the sliders button and check that the session settings show above the message field.

7. Open the Workspaces sheet. Tap Add and check that it shows Open Folder, Connect Runtime and Connect with SSH. Swipe left on a folder and check that Remove is easy to read. Touch and hold a folder and check the menu.

8. Change to the Paper light theme and repeat steps 2, 3 and 7. Check that all text is easy to read.

Report controls that do not fit on the screen, text that is hard to read, commits with the wrong files, lost changes and crashes, with reproduction steps, device model, iOS version and screenshots.
