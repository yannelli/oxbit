Source Control, Undo Last Commit and the agent composer

1. Open a Git folder that has changes and tap Changes. Check that the Commit button is below the message field. Check that each file row and each group header shows the added and removed lines in the same column.

2. Look at the buttons on each file row. Check that Discard shows a curved arrow and Stage shows a plus. Tap Discard on a file and check that the app asks before it discards the changes. Tap Cancel.

3. Connect to a computer runtime and open a Git folder that has changes. Write a message and tap Commit. Check that the message field shows "Committed", a short hash and your message, with Undo. Check that the file list does not move. Tap Undo. Check that your message is back in the field and the files are staged again.

4. On the same runtime folder, make a commit again. Open the menu next to Commit and tap Undo Last Commit. Check that the commit is removed and the files stay staged. On a folder on the device, check that the menu does not show Undo Last Commit.

5. With no AI model in Settings, look at the AI button in the message field. Check that it is dimmed. Tap it and check that the AI settings open. Add a model, go back to Changes, and tap the AI button. Check that it writes a commit message.

6. Open More. Check that the panels show the same names as the bottom bar: Files and Changes.

7. Open Agent. Check that the Auto button is next to the agent name and that the agent name is complete. Tap Auto and check that it turns orange.

8. Change to the Paper light theme and repeat steps 1, 3 and 6. Check that all text is easy to read.

Report controls that move when you tap them, text that is hard to read, commits with the wrong files, lost changes and crashes, with reproduction steps, device model, iOS version and screenshots.
