Inline completion options and agent logos

1. In Settings > Editor > AI, turn on AI inline completions with a model you have set up. Set Inline completion max lines to 1, type in a code file, and check that each suggestion is one line. Set it back to 2 and check that suggestions span up to 2 lines.

2. With a suggestion showing, press Delete or move the cursor. Check that the suggestion disappears and no new one appears until you type again.

3. Set Inline completion max tokens to 16 and check that suggestions get shorter. Set it back to 256.

4. Add a pattern to Inline completion excluded files that matches the open file, for example **/*.ts. Type in that file and check that no suggestion appears. Remove the pattern and check that suggestions return.

5. Turn on "Inline completion: send nearby problems" and "Inline completion: send other open files", open two or three files, and type in one of them. Check that suggestions still appear and match the code around the cursor.

6. Add a line to Inline completion instructions, for example "Use single quotes.", and check that suggestions follow it.

7. Open the Agent panel and start a conversation with Claude Agent or Codex. Check that the footer under the composer shows that agent's logo instead of the sparkle icon.

Report suggestions that ignore a setting, a missing or wrong agent logo, and crashes, with reproduction steps, device model, iOS version, and screenshots.
