Agent panel layout

1. In a folder on this iPhone, open the agent panel, start Oxbit Agent with Auto-apply edits on, and ask for a change to a file. Send a second message. Check that Reviewed agent edits shows right after the first reply, before your second message, and stays there.

2. Ask the agent for a reply with a long code line or a wide table, such as "show a 300-character line in a code block". Check that only the code block scrolls sideways and the conversation does not move left or right.

3. Make a turn fail, for example by turning on airplane mode before you send. Check that the error shows below that turn, that nothing stays in red above the conversation, and that the next message works after you turn airplane mode off.

Report edits or terminal output that collect at the bottom, conversations that scroll sideways, and errors that stay above the conversation, with reproduction steps, device model, iOS version, and screenshots.
