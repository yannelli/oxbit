## Renderer mappings

- CodeMirror: keyword, string, number, comment, type, function, property, variable, ident, text, tag, attr, punct, operator, heading, link, strong, emphasis. Tags use all five syntax style properties. Strong and emphasis preserve Markdown semantics. Gutter, cursor, guides, occurrences, selections, search and diagnostic decorations use semantic colors.
- xterm: foreground, background, cursor, cursorAccent, three selection properties, all 16 ANSI colors; SearchAddon receives match and active match backgrounds, borders and overview colors. Size, family, weight, line height, letter spacing and ligatures update without replacing the terminal. xterm has no font-style or variable-axis option; these properties apply to DOM/CodeMirror renderers only.
- Workbench and native-shell roots: cssVariables plus effective UI typography. Native popovers remain descendants of the originating root and inherit its variables. Web connection overlays explicitly apply the same variables.
- Rendered Markdown: document typography, preview background/foreground, semantic links, code, tables and quote chrome.
- Collaboration: local awareness cursor/selection values update with the theme; remote participants' colors are peer-provided identity data.

## Explicit exemptions

- Brand marks, logo URLs and brand accent in tokens.css remain host identity, as required by v1's boundary. The initial body fallback uses the catalog's dark workbench background before a session mounts.
- Row/tab/control sizes and responsive density are layout. Relative font-size ratios preserve existing hierarchy; font-style italic on preview tabs and text-decoration on missing files communicate state. Markdown strong/emphasis communicates document semantics.
- Numeric font values inside adapters come from resolved typography or explicit settings. Native font-face declarations under public/fonts register application assets, not role selection.
- Editor folding icons and transparent hit regions are geometry, not palette colors. Vendor CSS, external preview contents, OS dialogs, brand assets and application-emitted terminal truecolor are outside the owned surface inventory.
