The workbench

Your code, tools, and agents.
In one workspace.

Oxbit combines a CodeMirror editor with Git, language services, and coding agents. Connect a runtime for terminals and project tools, or use the on-device features on iPhone and iPad.

01 / Edit

Make space for your code.

Split views, multiple cursors, find and replace, formatters, and Markdown and HTML previews. Choose themes and icon packs for your workspace.

Explore language support →

02 / Ask

AI where you edit.

Enable inline completions for ghost text suggestions, or select code and run Edit Selection with AI. Suggestions use the model provider configured for Oxbit Agent. Inline completions are off by default.

New in v0.12.0 →

03 / Delegate

Choose your coding agent.

Enable Agent ACP in Extensions to use Codex, Claude Agent, Gemini CLI, and other ACP agents in a trusted runtime workspace. Review diffs, attach context, and return to sessions after a disconnect.

Oxbit Agent also runs on iPhone and iPad with your chosen model service. Provider accounts and usage costs are separate.

Set up agents →

04 / Run

Keep project tools close.

Stage changes, commit, browse history, and manage branches in Source Control. A connected runtime runs terminals, tasks, project services, and managed language servers.

Read the tasks guide →

Work across connections

Return to your workspace.

Browser workspaces store files, settings, layout, and drafts in IndexedDB. Runtime saves check file revisions, drafts survive failed saves, and surviving terminal and agent sessions reconnect. Commands with uncertain outcomes are inspected before another attempt.

Read the trust and recovery boundaries or compare what runs on each platform.
