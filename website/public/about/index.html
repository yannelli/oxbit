About Oxbit

An open-source IDE that brings files, terminals, Git, language tools, and AI agents to the devices you use.

What is Oxbit?

Oxbit is an IDE built with React and CodeMirror. It runs in a browser, on macOS and Linux, and on iPhone and iPad. The editor includes split views, search and replace, source control, previews, themes, and extensions.

Browser workspaces store files and drafts in browser storage. Connecting the Node runtime adds access to files on disk, terminals, tasks, Git, language services, and collaboration. The desktop app bundles a runtime; iPhone and iPad can edit local folders and connect to a runtime on another computer.

An independent open-source project

Oxbit is maintained and published by Ryan Yannelli. The public GitHub repository contains the application source, documentation, issue tracker, and release history.

The source is available under the MIT license. Bundled fonts and dependencies keep their own licenses, recorded in the third-party notices.

Choose how you work

  • Browser: use a browser workspace or install the CLI to open a project through a local runtime. See the quick start.
  • macOS and Linux: use the desktop app with its bundled runtime and connect to remote workspaces over SSH. See desktop setup.
  • iPhone and iPad: edit device folders, use on-device language services and Git, or connect to a computer for terminals and tasks. See iOS setup.

The downloads page lists platform requirements and installation options. The documentation explains runtime connections, agents, and workspace tools.

Follow development or contribute

Read the changelog for release changes. Report a reproducible bug or discuss an improvement in GitHub issues, or submit a pull request. The repository's development guide covers local setup and checks.

For help, visit support. For vulnerabilities, follow the private security reporting process.
