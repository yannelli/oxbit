Get help with Oxbit

Find setup instructions, report a bug, or contact the project maintainer.

Start with the documentation

The documentation hub links installation, runtime connections, SSH workspaces, agents, source control, and recovery guides. For installation options and platform requirements, visit downloads.

For runtime connection problems, check that the runtime is running and pair with its printed code. Terminals, tasks, Git, and language services require Trust workspace tools in Runtime connection. Read the runtime guide and workspace trust explanation before enabling tools for a project.

Report a bug or request a feature

Search existing GitHub issues first, then open an issue with enough information to reproduce the problem:

  • The Oxbit version or commit, and the build number for a TestFlight build.
  • Your device, operating system, and browser version, when applicable.
  • Whether the workspace uses browser storage, a device folder, a local runtime, or an SSH connection.
  • The steps to reproduce, what you expected, and what happened.
  • A small example, screenshot, or relevant log excerpt with secrets and personal information removed.

GitHub issues are public. Remove API keys, tokens, pairing codes, private source code, and personal information before submitting a report. Send undisclosed vulnerabilities through the private security reporting process.

For a feature request, describe the task you want to complete and the behavior that would help.

Send iPhone and iPad beta feedback

If you installed Oxbit through TestFlight, use TestFlight's feedback controls to send a screenshot or crash report. Include the device, iOS or iPadOS version, build number, and steps that led to the problem.

Use GitHub issues for a public report that you can follow and update. The changelog lists release changes.

Contact the maintainer

For general questions that need a private conversation, email Ryan Yannelli at ryanyannelli@gmail.com. For a security vulnerability, use the same address and include the details listed in the security reporting policy.

The privacy policy explains information shared through support, connections, and optional services.

Have a reproducible issue?

Check existing reports and include the steps needed to reproduce yours.
