Managed language servers

Completion, diagnostics, navigation, and formatting in trusted runtime workspaces.

Source Control

Staging, commits, history, branches, remotes, stashes, and merge recovery.

Terminals and tasks

Import project commands. Run services, dependencies, and worktree lifecycle hooks.

Share Workspace

Revocable collaboration grants. Tool trust and access grants have separate controls.

Recovery that keeps its word

Browser workspaces persist files, settings, layout, and drafts in IndexedDB. Runtime workspaces check revisions before saving, preserve drafts, and reconnect surviving terminals. Commands with uncertain outcomes are not repeated automatically.

  • Drafts preserved
  • Revision checks
  • Terminal reconnect
  • Workspace JSON import / export

Platforms

One editor. Every screen.

The same workbench in a browser tab, in a native desktop window, and on an iPad next to your coffee.

Browser

Open a directory with browser directory access, or pair with a runtime for files on disk. Nothing to install.

Oxbit

macOS & Linux

The Tauri desktop app bundles Node, ripgrep, the terminal addon, and managed language services. Connect over SSH opens a remote folder; the host does not need Node.

iPhone & iPad

Edit the app's Documents folder or folders from Files. Connect to a runtime on another computer for terminals, Git, tasks, and language services. Pairing credentials live in Keychain.

Runtime

One command.
Your project, served.

oxbit starts a runtime, opens the editor in your browser, and returns to the shell. Run it again in the same project and it reuses the runtime. The printed URL carries a pairing code that the editor consumes and removes from the address bar.

oxbit ~/code/app
Open a project
oxbit src/main.ts
Open a file in the current project
oxbit --status
Report the runtime serving this workspace
oxbit --stop
Stop the workspace runtime
oxbit --desktop
Open an installed desktop app

Agent ACP

            
Use Codex ACP, Cursor ACP, or Amp Agent ACP in a trusted runtime workspace. Conversation history, editor context, permission controls, diff review, and subagent tracking. Disabled by default; enable it in Extensions.

Public SDK

            
Register commands, panels, settings, status items, output channels, and document views. The Bundle Inspector example ships in the repo.

            
import type { Extension } from '@oxbit/sdk';

export default {
  manifest: {
    manifestVersion: 1,
    id: 'example.hello',
    version: '1.0.0',
    sdk: '^1.0.0',
    activation: ['onCommand:hello.show'],
  },
  activate(ctx) {
    ctx.commands.register({
      id: 'hello.show',
      title: 'Hello: Show',
      run: () => 'Hello',
    });
  },
} satisfies Extension;
