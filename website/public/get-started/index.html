Browser + CLI

Start from your terminal.

On macOS or Linux, install Node 24, Git, and ripgrep first. Linux also needs Python, make, and a C++ compiler to build the terminal addon.

npm install -g @oxbit/cli --allow-scripts=@oxbit/cli,node-pty
oxbit ~/code/my-project

The --allow-scripts option permits the CLI and terminal addon install scripts on npm 12. See the npm installation guide for details.

  1. Open a project

    Replace ~/code/my-project with your folder, or run oxbit in the project. The command starts a runtime and opens the browser editor.

  2. Trust workspace tools

    In Runtime connection, select Trust workspace tools to enable terminals, tasks, Git, and language services. Do this for projects whose tools you trust.

  3. Find your commands

    Open the command palette with Ctrl + Shift + P, or Cmd + Shift + P on macOS. Enable Agent ACP in Extensions when you want coding agents.

Connect another device.

Run oxbit --lan on the computer holding your project to serve the runtime on your network. Pair the iPhone or iPad app with the printed code. For servers, follow the SSH guide and runtime configuration.

oxbit --status reports the current runtime. oxbit --stop stops it. Runtime pairing and tool trust are described on the security page.

Build from source.

Install Node 24, Bun 1.4.2, Git, ripgrep, and the native build tools listed in the repository. Follow the source setup in the README. The global source install links to your checkout.
