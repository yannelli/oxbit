Frequently asked questions

Direct answers about the project, supported platforms, agents, and where your data goes. For step-by-step help, visit the documentation.

What is Oxbit?

Oxbit is an open source IDE. It runs in a browser, on macOS and Linux, and on iPhone and iPad. A connected Node runtime provides files, terminals, Git, tasks, language services, and agents.

Is Oxbit free and open source?

Oxbit’s source code is available under the MIT license. Model providers and third-party agent services have their own accounts, plans, and usage costs.

Which operating systems does Oxbit support?

The desktop app targets Apple Silicon Macs with macOS 26 or later and Ubuntu 24.04 or later on x64 and arm64. The iPhone and iPad app requires iOS 26 or iPadOS 26 or later and is distributed through TestFlight. The CLI opens the editor in your browser on macOS or Linux.

Does Oxbit run on Windows?

The current desktop release targets macOS and Linux. There is no Windows desktop installer in the documented release targets.

Do I need a computer to use Oxbit on iPhone or iPad?

You can edit Documents and folders from Files, use on-device Git and language services, and run Oxbit Agent with your chosen model service without a computer. Terminals and tasks require a connected computer runtime.

What is the Oxbit runtime?

The runtime is a process on the computer holding your project. It serves files and project tools to the editor. Running oxbit starts it and opens the browser editor. Pairing authorizes a connection; workspace tool trust separately enables commands, tasks, Git, and language services.

Which coding agents can I use?

Enable Agent ACP in Extensions in a trusted runtime workspace to use Codex, Claude Agent, Gemini CLI, GitHub Copilot, Cursor, Amp, agents from the ACP Registry, or a custom ACP executable. Oxbit Agent also runs on iPhone and iPad, and Oxbit Agent CLI runs in a terminal or through ACP.

Where does my code go when I use AI features?

AI agents and AI editing send prompts and relevant code or context to the model service you configure. Git remotes, extensions, and collaboration use the destinations you choose. The privacy policy describes local storage, optional connections, and service data handling.

Can I work on a remote server?

The desktop app connects to remote folders over SSH. The iPhone and iPad app supports SSH and SFTP and can connect to a remote runtime for terminals and tasks. Follow the runtime and SSH guides for supported hosts and setup.

Where can I report a bug or ask for help?

Use the public GitHub issue tracker for reproducible bugs and feature requests. Include your Oxbit version, platform, steps, and relevant logs with credentials removed. Report security vulnerabilities privately to ryanyannelli@gmail.com.
