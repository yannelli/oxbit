v0.12.0October 18, 2026

AI editing at the cursor

Oxbit adds AI inline completions and Edit Selection with AI.

  • Enable AI inline completions in Editor settings to see suggested text as you type. Accept it with Tab or dismiss it with Escape.
  • Select code and run Edit Selection with AI from the command palette. Review the highlighted replacement and restore the original selection with one Undo.
  • On iPhone and iPad, set up Oxbit Agent with an OpenAI, Anthropic, or OpenAI-compatible API key, or sign in with ChatGPT.

v0.11.7October 13, 2026

JavaScript in HTML previews

Run JavaScript in HTML previews in the desktop app. On iPhone and iPad, previews of HTML files with scripts offer a Run JavaScript button so you choose when the script runs.

v0.11.0October 12, 2026

Agent settings and context visibility

Oxbit Agent adds settings commands, a context view, and settings panels in the terminal interface.

  • Use /context to see the context window and its breakdown across instructions, skills, tools, and messages.
  • Use commands including /config, /skills, /hooks, /mcp, /instructions, and /providers in Oxbit Agent CLI.
  • Adjust Auto-compact and Compact at beside Model and Mode in the Agent CLI session settings.

Release notes and downloads · iOS testing notes

v0.10.0October 12, 2026

Oxbit Agent CLI and edit controls

Oxbit introduces its terminal coding agent and expands the Agent panel controls.

  • Start Oxbit Agent CLI on a connected computer runtime. The CLI supports goals, loops, compaction, skills, hooks, MCP, providers, and snapshots.
  • Turn Auto-apply edits on to save changes as they arrive, or leave it off to review each change before applying it. Use Ask, Accept edits, and Full auto modes in Oxbit Agent.
  • New agent conversations receive generated titles after the first reply.
  • iOS agent updates keep long turns and backgrounded turns working.
